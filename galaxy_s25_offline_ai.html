Galaxy S25 Offline AI Setup

📱 Method 1: Google Play Store Easiest
  1. Open the Google Play Store and search for Layla Lite.
  2. Download and open the app.
  3. Follow the onboarding steps to download a Llama 3.2 (1B or 3B) model internally.
  4. Turn off your mobile data/Wi-Fi and start chatting 100% offline.
🛠️ Method 2: GitHub + Custom GGUF Advanced
  1. Download and install ChatterUI from its official GitHub repository releases page.
  2. Go to Hugging Face on a browser and download a mobile-optimized GGUF model file (e.g., Llama-3.2-3B-Instruct-Q4_K_M.gguf).
  3. Open ChatterUI, navigate to settings, select the local execution backend, and link it to your downloaded .gguf file.
  4. Enter Airplane Mode to experience total offline privacy.
